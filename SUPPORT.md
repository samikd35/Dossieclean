# Support

## Getting Help

Use one of the channels below based on the type of request:

- Questions and usage help: open a GitHub Discussion.
- Bug reports: open a GitHub Issue using the bug template.
- Feature requests: open a GitHub Issue using the feature template.
- Security reports: do **not** open a public issue. Follow [SECURITY.md](SECURITY.md).

## Before Opening an Issue

- Search existing issues/discussions first.
- Include your Python version, OS, and relevant logs.
- Share reproducible steps and a minimal example.

## Response Expectations

This project is community-maintained. Best-effort response targets:

- Triage for new issues: within 5 business days.
- Follow-up after initial triage: as maintainer availability permits.
